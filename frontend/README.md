# PathGuard frontend

React, TypeScript, and Vite shell. Feature work stays out of `src/App.tsx`, `src/shell.tsx`, and `src/index.css` unless this foundation issue owns the change.

```bash
npm install
npm run dev
npm run build
npm test
```

Fixture mode is selected in the header. It reads committed fixtures in `src/api.ts` and does not call CSDI, HKO, or Marine Department.
